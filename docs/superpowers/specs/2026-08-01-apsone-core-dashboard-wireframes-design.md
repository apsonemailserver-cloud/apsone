# APSOne Core Dashboard Wireframes Design

## Objective

Extend the existing `mockup apsone` Figma file with six monochrome, low-fidelity desktop screens based on the supplied production screenshots. The screenshots define content and workflow only; layouts must be simplified and visibly provisional.

## Screens

1. Dashboard Overview
2. Employee Profile
3. Today's Schedule
4. Schedule List
5. Create / Update Schedule
6. Shift Management

## Shared Visual System

- Each screen is a 1440 × 900 desktop frame.
- Use only white, black, and neutral gray fills and strokes.
- Use Inter typography and simple text or geometric icon placeholders.
- Do not use blue, gradients, illustrations, photos, polished shadows, or production-level decoration.
- Arrange the new frames in a second horizontal row below the authentication wireframes.
- Use a shared 220 px sidebar and a compact 76 px utility header.
- Keep navigation labels recognizable while reducing the menu to Dashboard, Profile, Schedule, Shift, Attendance, Assignment, Users, Documents, Training, and Leave.
- Mark the active menu item with a dark-gray fill or dark border.
- Include a small `LOW-FIDELITY WIREFRAME` annotation on every screen.

## Screen Designs

### Dashboard Overview

- Greeting and station filter placeholder.
- Three compact station summary cards.
- Four KPI cards using neutral fills.
- One line-chart placeholder and one role-distribution placeholder.
- No production chart colors or exact production geometry.

### Employee Profile

- Avatar placeholder and concise identity summary.
- Employment and biodata tab placeholders.
- Six employment detail cards plus a compact status panel.
- No illustrated avatar or exact production card layout.

### Today's Schedule

- Operational-day summary banner.
- Four compact metric cards.
- Current-shift summary with time and staff count.
- Two-column staff list with six representative rows and neutral status tags.

### Schedule List

- Four summary metrics.
- Month and scheduled-days summary.
- Simplified two-week calendar grid showing representative scheduled, off, and empty dates.
- Calendar is conceptual, not a complete reproduction of the production month.

### Create / Update Schedule

- User count summary.
- Auto-create and import action placeholders.
- Search field.
- Five-row user table with NIP, name, role, and edit action.

### Shift Management

- Total-shift summary.
- Create-shift action.
- Five-row shift table containing ID, name, start time, end time, workforce, and actions.
- Omit detailed timestamps to keep the wireframe concise.

## Prototype Flow

- Sidebar Dashboard links to Dashboard Overview.
- Sidebar Profile links to Employee Profile.
- Sidebar Schedule links to Schedule List.
- Schedule List exposes links to Today's Schedule and Create / Update Schedule.
- Sidebar Shift links to Shift Management.

## Success Criteria

- All six screens are editable and consistently arranged in Figma.
- Content hierarchy and key workflows remain understandable.
- The designs do not resemble the supplied production screenshots pixel-for-pixel.
- Every fill and stroke is neutral grayscale.
- No nodes extend beyond their containing screen.
- Prototype links between the six screens are active.
